# 🚀 Express API Pro — Production-Ready Express 5 Boilerplate

A modern, secure, and documented Express.js 5 API starter built for speed and scalability.  
This boilerplate saves you days of setup and is **ready for production**, **Docker deployment**, and **API documentation out of the box**.

---

## 🌟 Features

✅ Express 5 (latest syntax)  
✅ MongoDB (Mongoose 8)  
✅ JWT Auth + Refresh Tokens  
✅ Role-Based Access Control (RBAC)  
✅ Zod Validation  
✅ Swagger API Docs (`/api/docs`)  
✅ Winston Logging + Morgan Dev Logs  
✅ Helmet, CORS, Rate Limiting, Cookie Parser  
✅ Docker & Compose Ready  
✅ Postman Collection Included  
✅ AI Route Example (Pro version)
